Heads up: as of the June 2026 Discord change, application widgets like this one can currently only be added by the application owner's account. Staff members may not be able to add it to their own profile yet — this is a Discord-side restriction, not a bug here. Once Discord lifts it, add the staff member's Discord user ID above and it'll start receiving pushes automatically.
Open Discord profile settings →
  1. Open Discord on desktop or web (mobile isn't supported for widgets).
  2. Go to User Settings (gear icon) → Profiles tab.
  3. Scroll to Profile Widgets and press Add Widgets.
  4. Find your server's widget (the display name you set during setup) in the list and add it.
  5. Press Save to confirm.
